# Fndesk 飞牛主题库 & 壁纸库接入规范

本文档说明如何制作符合 Fndesk 规范的主题库（`theme.json`）和壁纸库（`bg.json`）文件，在 Fndesk 一键切换使用。

主题库涵盖飞牛：登录背景、登录 LOGO、桌面背景、设备 LOGO、Favicon 等；壁纸库涵盖登录背景与桌面壁纸两类独立资源。

---

## 一、主题库（`theme.json`）

### 1.1 文件结构

支持两种 JSON 结构：

- 包格式：`{ "_meta": {...}, "themes": [...] }`（远程库源的标准格式）
- 裸数组：`[...]`（本地 `deskdata/theme.json` 的标准格式）

**完整示例（包格式）**

```json
{
  "_meta": {
    "name": "XXX 主题库",
    "desc": "高品质主题集合，涵盖自然、动漫、科技等多种风格",
    "from": "制作者 / 提供者 名字"
  },
  "themes": [
    {
      "ID": 1,
      "标题": "明日方舟终末地 - 萤石",
      "t0": "http://123.com/萤石/thumbnail.webp",
      "t1": "http://123.com/萤石/loginLogo.png",
      "t2": "http://123.com/萤石/loginBg.mp4",
      "t3": "http://123.com/萤石/deviceLogo.png",
      "t4": "http://123.com/萤石/wallpaper.mp4",
      "t5": "http://123.com/萤石/favicon.png"
    },
    {
      "ID": 2,
      "标题": "开心肥牛",
      "t0": "http://123.com/开心肥牛/thumbnail.webp",
      "t1": "http://123.com/开心肥牛/loginLogo.png",
      "t2": "http://123.com/开心肥牛/loginBg.mp4",
      "t3": "http://123.com/开心肥牛/deviceLogo.png",
      "t4": "http://123.com/开心肥牛/wallpaper.mp4",
      "t5": "http://123.com/开心肥牛/favicon.png"
    }
  ]
}
```

### 1.2 主题对象字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `ID` | 数字 | ✅ | 主题唯一标识 |
| `标题` | 字符串 | ✅ | 主题名称，显示在卡片按钮上 |
| `t0` | URL | ⭕ | 缩略图（支持常见图片格式，长边 240px） |
| `t1` | URL | ✅ | 登录 Logo（支持常见图片格式，建议小于 300×130） |
| `t2` | URL | ✅ | 登录背景图（支持常见图片格式或 MP4 视频） |
| `t3` | URL | ✅ | 设备 Logo（支持常见图片格式，建议 128×128） |
| `t4` | URL | ✅ | 桌面壁纸（支持常见图片格式或 MP4 视频） |
| `t5` | URL | ⭕ | 网页 Favicon（建议 128×128） |

### 1.3 `_meta` 字段（可选）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `name` | 字符串 | ⭕ | 主题库名称，显示在工具的下拉列表中 |
| `desc` | 字符串 | ⭕ | 主题库介绍 |
| `from` | 字符串 | ⭕ | 提供者信息 |

> 💡 `_meta` 可整体省略。省略时下拉列表中显示"未知主题库"。

## 二、壁纸库（`bg.json`）

### 2.1 文件结构

支持两种 JSON 结构：

- 包格式：`{ "_meta": {...}, "wallpapers": [...] }`（远程库源的标准格式）
- 裸数组：`[...]`（本地 `deskdata/bg.json` 的标准格式）

> 两种结构会被自动识别，无需关心。

**完整示例**

```json
[
  {
    "ID": 1,
    "p0": "https://example.com/wallpapers/1/thumbnail.webp",
    "p1": "https://example.com/wallpapers/1/wallpaper.webm"
  },
  {
    "ID": 2,
    "p1": "https://example.com/wallpapers/2/wallpaper.jpg"
  },
  {
    "p0": "https://example.com/wallpapers/3/thumb.png",
    "p1": "https://example.com/wallpapers/3/bg.jpg"
  }
]
```

> 第二、三两条分别展示 **p0 省略** 与 **ID 省略** 两种写法，均为合法。

### 2.2 壁纸对象字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `ID` | 数字 | ⭕ | 壁纸唯一标识，用于排序；缺失时不影响加载 |
| `p0` | URL | ⭕ | 缩略图（支持常见图片格式，长边建议 240px；**省略时自动用 `p1` 代替**） |
| `p1` | URL | ✅ | 壁纸资源（支持常见图片格式，或 MP4 / WebM 视频） |

> ⚠️ `p1` 是唯一必填字段——它是壁纸本体，也是用户实际应用的资源。缺少 `p1` 的条目会被自动过滤，不出卡。

### 2.3 `_meta` 字段（可选）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `name` | 字符串 | ⭕ | 壁纸库名称，显示在工具的下拉列表中 |
| `desc` | 字符串 | ⭕ | 壁纸库介绍 |
| `from` | 字符串 | ⭕ | 提供者信息 |

> 💡 壁纸库的 `_meta` 可整体省略，与主题库行为一致。

### 2.4 与主题库的区别

| 维度 | 主题库 | 壁纸库 |
|------|--------|--------|
| 数据文件 | `theme.json` | `bg.json` |
| 包格式字段 | `{ "themes": [...] }` | `{ "wallpapers": [...] }` |
| 每个对象字段 | `ID / 标题 / t0~t5`（一整套主题） | `ID / p0 / p1`（单一壁纸资源） |
| `p0`（缩略图）| 可选，无回退 | 可选，**缺失时用 `p1` 回退** |
| 视频缩略图 | 不支持 | 支持 `.webm` / `.mp4` 直接作为缩略图 |
| 应用方式 | 一次应用整套主题 | 单张壁纸，用户自行选择"登录背景"或"桌面背景" |

## 三、库源管理（`*_list.json`）

主题库和壁纸库共用一套"库源列表"机制：本地 `deskdata/*_list.json` 列出已选的库源 URL，工具每次进入时还会拉取远程默认列表、按 URL 去重合并。

### 3.1 `theme_list.json`（主题库源）

结构示例：

```json
[
  {
    "name": "Fndesk 主题库",
    "desc": "Fndesk 内置默认主题库",
    "from": "米恋泥",
    "url": "https://fndesk.imcq.top/theme/theme.json"
  }
]
```

### 3.2 `bg_list.json`（壁纸库源）

结构示例：

```json
[
  {
    "name": "Fndesk 动态壁纸库",
    "desc": "Fndesk 内置默认动态壁纸库",
    "from": "米恋泥",
    "url": "https://fndesk.imcq.top/theme/bg.json"
  }
]
```

### 3.3 库源条目字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `name` | 字符串 | ⭕ | 库源名称，显示在下拉列表中；缺失时显示"未命名" |
| `desc` | 字符串 | ⭕ | 库源描述 |
| `from` | 字符串 | ⭕ | 提供者信息 |
| `url` | 字符串 | ✅ | 指向 `theme.json` 或 `bg.json` 的公开 URL |

> 💡 用户可在 Fndesk 工具内通过"编辑库源"弹窗增删改条目，数据保存回对应的 `*_list.json`。

## 四、发布方式

把 `theme.json` 或 `bg.json` 放到可公开访问的 URL 后，有两种方式让用户使用：

### 方式 1：用户自行添加

用户进入工具 → 对应区域的**库源管理 → 编辑 → 添加**，粘贴你的 URL，工具会自动从 `_meta` 读取库源名称、描述、作者信息。

### 方式 2：提交到 Fndesk 作者收录

把你的 `theme.json` 或 `bg.json` 扔给 **米恋泥**，审核通过后会加入对应库源默认列表。

## 五、注意事项

| 项 | 说明 |
|----|------|
| 🎬 动态视频 | 推荐使用 **H.264 编码的 MP4**；嵌入式浏览器对 WebM 支持有限，视频缩略图可能显示为占位图标 |
| 🔧 主题固定字段 | `t1` ~ `t5` 是固定字段，未来可能扩展更多 |
| 🔧 壁纸必填字段 | `p1` 是唯一必填字段；`ID` 与 `p0` 均可省略 |
| 🌱 共创生态 | 欢迎大家参与制作主题库与壁纸库，让飞牛更有趣！ |
